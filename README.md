
# Basic Chatbot Using Python

## Project Description
This project is a simple rule-based chatbot developed
using Python. It interacts with users through text
input and provides predefined responses.

## Features
- Responds to greetings.
- Answers how are you questions.
- Tells its name.
- Explains who created it.
- Exits when the user types bye.

## Technologies Used
- Python 3

## Concepts Used
- Functions
- While Loop
- If-Elif-Else
- User Input and Output
- String Methods

## How to Run

1. Install Python.
2. Download or clone this repository.
3. Open the project folder in VS Code.
4. Run the following command:

python chatbot.py
